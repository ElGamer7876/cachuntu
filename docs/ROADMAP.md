# Initial roadmap

1. Define the Cachuntu concept and identity.
2. Set up the repository, licenses, and release policy.
3. Build the Ubuntu 26.04 LTS based system.
4. Produce a bootable, installable preview ISO.
5. Test in virtual machines and on supported hardware.
6. Publish a verified Cachuntu preview.
7. Prepare the first public release.

The ISO and installation validation remain in progress.
